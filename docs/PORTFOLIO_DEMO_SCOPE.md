# Public Portfolio-Demo Boundary

ClearPath QMS has two deliberately separate layers:

| Layer | Visibility | Contents |
|---|---|---|
| Core product | Private | Product roadmap, complete implementation, detailed business logic, production integrations, private data, and future compliance-rule content |
| Portfolio demo | Public | Read-only interface, synthetic data, limited workflow examples, screenshots, architecture overview, and selected illustrative code |

## Public-demo rules

The public demo may show the user experience and high-level system design. It must
not include real customer or clinical data, credentials, production databases,
production endpoints, proprietary compliance rules, or detailed product roadmap
materials.

The demo is not a validated QMS, a regulatory submission tool, or a claim of
compliance with any standard. It is a portfolio demonstration of engineering
traceability, systems architecture, and workflow design.
